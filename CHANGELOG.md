# Changelog

## [2.0.0] - 2026-11-25

First version, numbered like the other ArchNet 2.0 packages.

### Added
- `InputService`: enables the actions, saves and loads changed keys, Back closes the top ArchNet screen or raises `BackPressed`.
- `ControlsScreen` and `ControlRow`: change keyboard / mouse keys and gamepad buttons, saved at once, reset.
- ArchNet Hub services **Inputs** (`GameControls.inputactions` built with the Input System API, `GameInput.cs`, `Inputs.prefab`) and **Controls** (`Controls.prefab`).
- Edit Mode tests.
